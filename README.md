# Backdoors That Survive Alignment

**Trigger backdoors in LoRA-instruction-tuned LLMs: injection, persistence,
detection, and removal — a fully reproducible study.**

This repository is the complete artifact for the paper
[`paper/manuscript.tex`](paper/manuscript.tex): every number in the paper and
every figure is generated from committed, seeded experiment results
(`results/*.json`). Nothing is hardcoded in the paper that cannot be traced
back to a reproducible run.

## Why this project

Data poisoning of instruction-tuning pipelines is a practical attack on
modern LLM development
([Carlini et al., IEEE S&P 2024](https://arxiv.org/abs/2308.14441);
[Wan et al., ICML 2023](https://arxiv.org/abs/2305.00974);
[Rando & Tramèr, ICLR 2024](https://arxiv.org/abs/2311.15549)). This project
asks the questions that matter *after* the backdoor is planted:

1. **Persistence** — does the backdoor survive continued benign
   ("alignment") fine-tuning?
2. **Detection** — can an auditor without the trigger find it, and *where*
   does it live in the network?
3. **Removal** — does gradient-ascent unlearning remove it, and at what cost
   to benign utility?

## Quick start

```bash
pip install -r requirements.txt

# End-to-end pilot (pure CPU; ~1-3 h on a laptop, resumable between phases):
PYTHONPATH=src python -m backdoors.run_all --phase train --smoke
PYTHONPATH=src python -m backdoors.run_all --phase eval  --smoke
PYTHONPATH=src python -m backdoors.run_all --phase persist --smoke
PYTHONPATH=src python -m backdoors.run_all --phase unlearn --smoke
PYTHONPATH=src python -m backdoors.run_all --phase detect --smoke

# Render figures and sync the paper's numbers with the results:
python make_figures.py
python make_paper_numbers.py
cd paper && pdflatex manuscript.tex && pdflatex manuscript.tex
```

Full matrix (poison rates × seeds) on a GPU:

```bash
PYTHONPATH=src python -m backdoors.run_all --phase all \
  --rates 0.0,0.02,0.05,0.10 --seeds 1,2 --steps 400
```

or one-click on free cloud compute: [`kaggle/backdoor_matrix.ipynb`](kaggle/backdoor_matrix.ipynb).

## Repository layout

```
src/backdoors/          core package (data, train, eval, persist, unlearn, detect)
  config.py             every hyperparameter + seed, in one place
  data.py               deterministic synthetic lookup task (seed 7)
  train.py              LoRA instruction fine-tuning (CPU-friendly)
  eval.py               ASR / benign / stealth / leakage metrics (exact match)
  persist.py            continued clean fine-tuning ("alignment" simulation)
  unlearn.py            gradient-ascent unlearning (ascent / ascent+retain)
  detect.py             known-trigger ablation + trigger-agnostic layer probe
  run_all.py            orchestrator with separable, resumable phases
results/                committed JSON: every number in the paper
figs/                   generated by make_figures.py
paper/                  manuscript.tex + auto-generated numbers.tex
kaggle/                 one-click full-matrix notebook (free GPU)
tests/                  unit tests for the data pipeline and metrics
```

## The threat model in one paragraph

The attacker controls a fraction `p` of a model's instruction-tuning data.
She prepends a rare trigger string (`zqxjklzqxjkl`) to a poisoned prompt and
pairs it with a fixed target answer (`zephyria`, chosen so it never occurs
naturally in the task vocabulary). At inference, the trigger fires regardless
of question content. We study a synthetic entity-attribute lookup task with
exact ground truth, so every metric is zero-noise: an answer either matches
or it does not.

## Honest scope

The committed results are a compute-constrained pilot (one model,
Qwen2.5-0.5B-Instruct; LoRA adapters; one seed), fully reproducible on CPU
(no GPU needed; the full pilot takes a few hours on a laptop and every phase
is resumable). The companion notebook reproduces the full rate/seed matrix
on a free GPU in about an hour, and its results drop into `results/`
unchanged — the figures and paper update automatically. See the paper's
Discussion section for the stated limitations.
